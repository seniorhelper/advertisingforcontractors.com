Where it goes

Where the code goes on your platform

One block, pasted once, right before the closing body tag. Here is exactly where that lives on whatever you are already using. If you cannot find it, call us and we will walk you through it on the phone for nothing.

Most common

WordPress

Appearance, then Theme File Editor, then footer.php, just above </body>. Safer option: install a snippet plugin like WPCode and paste it into a footer snippet, so a theme update cannot wipe it out.

E-commerce

Shopify

Online Store, Themes, Edit code, then layout/theme.liquid. Scroll to the bottom and paste above </body>. Works on every theme.

No code editing

Squarespace

Settings, Advanced, Code Injection, Footer. Paste and save. Nothing else to touch.

No code editing

Wix

Settings, Custom Code, Add Custom Code. Set it to load on all pages and place it at "Body — end".

Designer tools

Webflow, Duda, GoDaddy

All three have a footer or custom code box in site settings. Paste it there, then publish — on Webflow especially, it will not appear on the live site until you hit publish.

Static sites

Plain HTML

Open the file, paste near the bottom before </body>, upload. Several pages? Paste it on each, or drop it in a shared footer include.

Questions people actually ask

Is the contractor chatbot really free?
Yes, and free forever. There is no account, no email address, no credit card and no monthly fee. The builder runs in your browser and hands you a block of code you own outright. Nothing is metered because nothing reports back to us.
What is the catch?
There is no catch and no obligation, not even a link back. The code runs inside your own page, in your visitor's browser, so there is nothing for us to meter and nothing for us to bill. We give it away because contractors who eventually hire us usually start by trusting something we gave them first. If you never call us, the chatbot still works.
Do I need to know how to code?
No. Pick your trade, edit the questions and answers in plain English, then copy one block of code and paste it just before the closing body tag of your website. If you can edit your site's footer, you can install this.
Will it work on WordPress, Wix, Shopify or Squarespace?
Yes. Anywhere you can paste HTML: a WordPress footer or code snippet plugin, Shopify theme.liquid, Squarespace code injection, Wix custom code, Webflow footer code, GoDaddy or Duda custom code, or a plain HTML file.
Is this an AI chatbot or a rule-based chatbot?
Rule-based. It answers the questions you wrote answers for and never makes anything up. For a contractor that is the safer choice, because a rule-based bot cannot invent a price, a warranty or a promise you did not approve. A homeowner cannot screenshot a number your chatbot hallucinated and hold you to it.
How does the chatbot get leads to me?
Turn on the message form and a visitor can leave a name, phone number and note. It opens their own email app addressed to you, so the lead lands in your inbox with no database, no server and no privacy paperwork.
Does the chatbot slow my website down?
Barely. The whole widget is a single block of code around 10 KB with no outside requests, no tracking scripts and no third party server call. It loads with your page and runs in the browser.
